# Flywheel Account Manager Assessment

Self-contained candidate screening assessment for the Account Manager role at Flywheel CFO & Bookkeeping. Single static HTML file — no backend, no build step.

- Candidates complete 5 timed sections and receive a completion code to paste into their Upwork proposal.
- Reviewer console: "Reviewer access" link in the footer. Passcode is set in `ADMIN_PASS` at the top of the script in `index.html`.
- Grading, timing benchmarks, and anti-cheat flags (tab switches, paste detection) are built in.

## Deploy

Static site — Vercel auto-detects. No config needed.
